# 测试规格

## 后端
- 单元：78 张牌完整性、抽牌数量、无重复、正逆位合法、牌阵配置校验。
- 数据库：唯一约束、外键、事务、迁移、幂等种子。
- API：参数边界、认证、权限、分页、统一错误格式。
- Agent：成功、超时、无效 JSON、缺字段、伪造牌面、伪造来源、修复失败。
- RAG：正逆位过滤、来源可追溯、重复内容去重、空结果处理。

## 前端
- 表单必填和长度限制。
- 请求加载、错误和重试状态。
- 防止重复提交。
- 牌位/正逆位显示。
- 历史记录刷新恢复。
- 认证过期行为。

## E2E
1. 注册/登录。
2. 选择牌阵并提交问题。
3. 后端创建 Reading。
4. 展示正确牌数和牌位。
5. 请求解读并显示结构化结果。
6. 追问。
7. 刷新后恢复记录。
8. 删除记录。
9. 验证其他用户不能访问该记录。

## 质量门槛
- 核心规则和权限测试必须通过。
- 牌位一致率、引用 ID 有效率目标为 100%。
- 至少 30 条人工审核的 AI 评估用例。
- 不报告未实际运行的测试为通过。
